# Security Policy

## Supported Versions

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive information leakage (such as private keys or real production credentials) in this repository:

1. **Do NOT** open a public issue.
2. Contact the maintainer directly via email: `aswincp1705@gmail.com`.
3. Provide details regarding the potential vulnerability, affected files, and steps to reproduce.
4. We will review and address valid reports promptly.

## Lab Security Notice
- Configurations in this repository are designed for **laboratory and educational simulation** in GNS3, EVE-NG, or Cisco dCloud environments.
- Prior to deploying into a production enterprise environment, replace all lab credentials, generate enterprise CA-signed certificates, and restrict network device admin interfaces with Management Plane Protection (MPP) and Access Control Lists (ACLs).
